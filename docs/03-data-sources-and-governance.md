# Data Sources and Governance

## Candidate Data Sources

- FIRs and police reports
- Call Detail Records (CDRs)
- Financial transaction records
- Surveillance reports
- Social media intelligence
- Criminal history databases
- Intelligence agency reports

## Data Characteristics to Assess

- Structured vs unstructured ratio
- Missingness and inconsistency
- Identity ambiguity (aliases, spelling variations)
- Temporal completeness
- Geospatial precision

## Governance Principles

1. **Legality**: process data only within authorized legal frameworks.
2. **Purpose Limitation**: use data strictly for investigation and analysis goals.
3. **Access Control**: role-based access to sensitive entities and relationships.
4. **Auditability**: maintain traceability from insight to source evidence.
5. **Minimization**: retain only required fields and durations.
6. **Security**: encryption, secure storage, and monitored access.

## Research-Phase Governance Checklist

- [ ] Source-level authorization status documented
- [ ] Data classification tags defined (public/restricted/confidential)
- [ ] PII handling policy drafted
- [ ] Data retention and deletion policy drafted
- [ ] Chain-of-custody requirements identified
- [ ] Risk register for misuse and bias initiated
