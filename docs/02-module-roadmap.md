# Module Roadmap

## Six-Part Functional Breakdown

| Part | Module | Primary Focus | Research Outputs |
|---|---|---|---|
| 1 | Data Collection & Preprocessing | Collect, clean, normalize, and structure multi-source data | Source inventory, schema draft, normalization rules |
| 2 | NLP & Entity Resolution | Extract entities and identify duplicate/same entities | Entity taxonomy, extraction strategy, resolution criteria |
| 3 | Criminal Knowledge Graph | Build interconnected criminal intelligence graph | Graph ontology, node-edge definition, relationship matrix |
| 4 | Graph Analytics & Network Detection | Find communities, key entities, and hidden relationships | Network metrics plan, community strategy, influence criteria |
| 5 | AI-Based Anomaly & Link Prediction | Predict missing links and detect suspicious patterns | Feature strategy, anomaly hypotheses, model evaluation plan |
| 6 | Explainable Intelligence & Investigator Dashboard | Convert analysis into actionable, explainable intelligence | Explanation framework, investigator view requirements, reporting format |

## Cross-Cutting Research Questions

1. What minimum data quality is required for reliable entity resolution?
2. Which relationship types are most useful for investigators?
3. How should confidence scoring be represented for inferred links?
4. What explainability level is necessary for operational adoption?

## Exit Criteria for Research Phase

- Scope for all six modules is documented.
- Data governance constraints are approved.
- Baseline evaluation strategy is defined.
- Prototype-ready backlog is prepared.
